# Jubber UI

Copy-paste friendly web UI for Jubber, the glossy jello assistant used on Artificial Mind Hive and AMH Agent Book.

## Quick start

Open `index.html` directly, or copy the markup from `SNIPPET.md` into a site and serve this folder.

The baseline in the first commit matches the version published on August 8, 2026. Later commits add the improved motion director and edge/glow treatment.

## Files

- `jubber.css` — transparent character, tooltip, proximity squash, and hover animation
- `jubber.js` — pointer-proximity behavior
- `assets/jubber.webp` — transparent Jubber artwork
- `index.html` — standalone demo
- `SNIPPET.md` — minimal copy-paste integration
